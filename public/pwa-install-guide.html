Install Arsip Digital

Panduan Install untuk iPhone & iPad

🍎 iOS / iPadOS
⚠️ Penting!

Panduan ini hanya untuk Safari browser. Chrome, Firefox, dan browser lain di iOS tidak support fitur "Add to Home Screen" untuk PWA.

1 Buka di Safari
Pastikan Anda membuka aplikasi ini menggunakan Safari browser, bukan Chrome atau browser lainnya.
2 Tap Tombol Share
Di bagian bawah Safari, tap tombol Share (ikon kotak dengan panah ke atas).
📤
3 Pilih "Add to Home Screen"
Scroll ke bawah di menu share, lalu tap "Add to Home Screen" atau "Tambah ke Layar Utama".
➕ 🏠
4 Konfirmasi Install
Edit nama aplikasi jika perlu (default: "Arsip Digital"), lalu tap tombol "Add" atau "Tambah" di pojok kanan atas.
5 Buka dari Home Screen
Kembali ke home screen iPhone/iPad Anda. Icon Arsip Digital akan muncul seperti aplikasi lainnya. Tap untuk membuka!
📱 ✨
✅ Setelah Install, Anda Akan Mendapatkan:
  • Icon aplikasi di home screen
  • Buka dalam mode fullscreen (tanpa address bar)
  • Bisa digunakan offline
  • Loading lebih cepat dengan cache
  • Notifikasi push (jika diaktifkan)
  • Auto-update otomatis

Butuh bantuan? Hubungi support atau admin aplikasi.
