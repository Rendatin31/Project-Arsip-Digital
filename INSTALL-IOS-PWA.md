# 📱 Panduan Install Arsip Digital di iPhone/iPad

## Untuk Pengguna iOS (iPhone/iPad)

Karena aplikasi iOS hanya bisa dibuild di Mac, kami menyediakan alternatif **PWA (Progressive Web App)** yang bisa diinstall langsung dari browser Safari. Aplikasi akan berfungsi seperti aplikasi native!

---

## 🎯 Apa itu PWA?

**Progressive Web App** adalah aplikasi web yang bisa:
- ✅ Diinstall ke home screen iPhone seperti app dari App Store
- ✅ Berjalan dalam mode fullscreen (tanpa address bar Safari)
- ✅ Bekerja offline (dengan cache)
- ✅ Tampil dengan icon di home screen
- ✅ Tidak perlu App Store atau Mac untuk build

---

## 📋 Cara Install di iPhone/iPad

### Langkah 1: Buka di Safari
1. Buka **Safari** di iPhone/iPad Anda
2. Ketik URL aplikasi di address bar (contoh: `https://arsip-digital.com`)
3. Tunggu halaman loading selesai

⚠️ **PENTING:** Harus pakai **Safari**, bukan Chrome atau browser lain!

---

### Langkah 2: Tambahkan ke Home Screen

1. Tap tombol **Share** (kotak dengan panah ke atas) di bagian bawah Safari
   
   ![Safari Share Button](https://support.apple.com/library/content/dam/edam/applecare/images/en_US/ios/ios15-iphone12-pro-safari-share-icon.png)

2. Scroll ke bawah, cari dan tap **"Add to Home Screen"** (Tambah ke Layar Utama)
   
   ![Add to Home Screen](https://support.apple.com/library/content/dam/edam/applecare/images/en_US/ios/ios15-iphone12-pro-safari-add-to-home-screen.png)

3. Edit nama aplikasi jika perlu (default: **"Arsip Digital"**)

4. Tap **"Add"** (Tambah) di pojok kanan atas

---

### Langkah 3: Buka Aplikasi

1. Kembali ke home screen iPhone Anda
2. Cari icon **"Arsip Digital"** 
3. Tap icon untuk membuka aplikasi
4. Aplikasi akan terbuka dalam mode fullscreen (seperti app native!)

---

## ✨ Fitur yang Didapat

Setelah install ke home screen, Anda akan mendapatkan:

✅ **Icon di Home Screen**
- Icon aplikasi seperti app lainnya
- Nama aplikasi: "Arsip Digital"

✅ **Mode Fullscreen**
- Tidak ada address bar Safari
- Tidak ada tombol back/forward
- Tampilan seperti aplikasi native

✅ **Offline Capability**
- Bisa buka aplikasi tanpa internet (halaman yang pernah dibuka)
- File yang sudah di-cache tetap bisa diakses

✅ **Push Notifications** (jika sudah dikonfigurasi)
- Notifikasi seperti app native
- Badge counter di icon app

✅ **Fast Loading**
- Loading lebih cepat karena cache
- Tidak perlu download dari App Store

---

## 🔄 Update Aplikasi

Aplikasi PWA akan auto-update ketika Anda:
1. Buka aplikasi saat ada koneksi internet
2. Service Worker otomatis cek update
3. Update di-download di background
4. Next time buka app, sudah versi terbaru

**Tidak perlu manual update dari App Store!**

## ❓ FAQ (Frequently Asked Questions)

### Q: Apakah ini aman?
**A:** Ya, sangat aman! PWA jalan di browser Safari yang sudah diamankan oleh Apple.

### Q: Apakah bisa akses kamera/galeri?
**A:** Ya, PWA bisa akses kamera dan galeri seperti app native (dengan izin user).

### Q: Apakah butuh internet terus?
**A:** Tidak! Setelah install, banyak fitur bisa jalan offline. Tapi untuk sync data tetap perlu internet.

### Q: Bagaimana cara uninstall?
**A:** Tahan icon di home screen → pilih "Remove App" → "Delete App" (sama seperti app lain).

### Q: Apakah butuh space banyak?
**A:** Tidak, hanya beberapa MB saja (jauh lebih kecil dari app native).

### Q: Kenapa harus Safari? Chrome tidak bisa?
**A:** Apple membatasi fitur PWA hanya untuk Safari di iOS. Chrome di iOS tidak support "Add to Home Screen" untuk PWA.

### Q: Apakah sama dengan app Android?
**A:** 99% sama! Fungsinya identik, hanya cara installnya saja yang berbeda.

## 🆘 Troubleshooting

### Masalah: Tidak muncul "Add to Home Screen"
**Solusi:**
- Pastikan pakai Safari (bukan Chrome/Firefox)
- Pastikan iOS versi 11.3 atau lebih baru
- Coba reload halaman (refresh)
- Pastikan sudah di halaman utama aplikasi

### Masalah: Icon tidak muncul di home screen
**Solusi:**
- Tunggu beberapa detik, kadang delayed
- Coba restart iPhone
- Cek di Library (swipe ke kiri di home screen)

### Masalah: App tidak buka dalam fullscreen
**Solusi:**
- Pastikan tap icon di home screen (bukan bookmark Safari)
- Uninstall dan install ulang
- Clear Safari cache: Settings → Safari → Clear History and Website Data

### Masalah: Aplikasi tidak load/blank screen
**Solusi:**
- Pastikan ada koneksi internet untuk first load
- Clear Safari cache
- Force close Safari dan coba lagi
- Restart iPhone
